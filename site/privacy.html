Privacy

Last updated 3 August 2026

Plimsoll collects nothing, transmits nothing, and has no server.

What Plimsoll collects

No data is collected. Plimsoll does not gather personal information, browsing history, message content, credentials, or usage analytics.

What Plimsoll stores, and where

Plimsoll stores your settings and a local history of usage readings so it can show a trend over time. This is written to your browser’s extension storage, on your own device. It is never uploaded. You can export all of it, or delete all of it, from Options → Data.

Network requests

Plimsoll makes requests to exactly one category of destination: the AI provider whose page you are currently viewing and already signed into. Those requests read usage information using your existing session, in the same way the page itself does.

There is no analytics, no telemetry, no crash reporting, no advertising identifier, and no third-party SDK. Plimsoll makes no request to any Plimsoll-operated server, because none exists.

Third parties

None. No data is sold, shared, or transferred to anyone, for any purpose.

Permissions

Permission Why
storage Save your settings and local usage history on your device.
Access to claude.ai, chatgpt.com, gemini.google.com Read usage information from the page you are on and show the panel there.

Plimsoll does not request the tabs permission and does not use <all_urls>.

Conversation export

The full build can export the conversation on screen to your clipboard or to a file you download. This is always something you start, one conversation at a time, never automatic. The data goes only where you send it. Plimsoll never receives it.

Children

Plimsoll is not directed at children and collects no data from anyone.

Changes

Material changes are recorded in the project changelog and published here before taking effect.

Contact

Raise a privacy concern via GitHub Issues, or privately per the project’s security policy.
