Plimsoll

Named for the load line on a ship’s hull — the mark showing how heavily it can safely be loaded.

Plimsoll shows how much of your AI chat allowance you have used, without leaving the page: context usage, session and weekly limits, and credit spend.

Plimsoll is read-only. It reports usage; it never modifies, bypasses, or extends any provider’s limits.

What it does

  • Context usage for the conversation you are in, shown as an estimate.
  • Session, weekly and credit usage on Claude, read from Anthropic’s own page.
  • A clear “not available on this site” wherever a provider publishes no figure.
  • Every reading labelled with where it came from, dimming when it goes stale, so a cached number never passes for a live one.

What it never does

  • Show a made-up number. No source means the bar reads n/a, never 0%.
  • Help anyone continue past a limit. There is no auto-resume and no bypass.
  • Collect anything. No server, no analytics, no third-party code.

Honesty about coverage

Anthropic publishes a usage page, so Claude’s session, weekly and credit meters are real readings. OpenAI and Google publish no equivalent, so on those sites Plimsoll shows a context estimate and says plainly that the rest is unavailable. It would be easy to render an empty bar instead. An empty bar reads as “0% used”, which is a lie that looks like data.
